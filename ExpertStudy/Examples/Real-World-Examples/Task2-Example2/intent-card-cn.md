# Case 04：SIV 私密投票覆盖消息提取

## 案例背景

SIV（Secure Internet Voting）研究可验证的互联网投票机制。Verifiable Private Overrides 是其面向胁迫和买票风险的扩展：在保持投票过程可验证的同时，允许符合规则的选民通过独立流程私密地覆盖先前选择。

## 代码在项目中的位置

本案例是从私密覆盖授权电路中的 `ExtractStringFromPoint` 逻辑提炼出的研究用对齐版本。该组件从序列化点的字节表示中读取长度信息和消息内容，选择需要参与摘要的字节，再把消息长度、内容摘要、策略 nonce 和选举标识组合为授权标签。

案例使用较短数组和简化摘要控制规模，但保留了编码、长度、字节选择和授权标签之间的预期数据流。

## 预期功能

1. 从 `encodedPoint` 的首字节按规定编码规则得到消息长度。
2. 根据 `selected` 选择消息字节，并将未选择位置置零。
3. 汇总所选内容并与 `expectedBodyDigest` 对照。
4. 将消息长度、内容摘要、`policyNonce` 和 `electionId` 绑定为最终授权标签。

## 输入信号及其语义

| 输入信号 | 形状 | 语义 |
|---|---:|---|
| `encodedPoint` | `[8]` | 包含长度元数据和消息内容的序列化点字节。 |
| `selected` | `[8]` | 每个位置是否纳入提取结果的布尔选择值。 |
| `expectedBodyDigest` | 标量 | 提取后消息内容应当匹配的预期摘要。 |
| `policyNonce` | 标量 | 区分不同覆盖授权或防止标签复用的策略 nonce。 |
| `electionId` | 标量 | 当前选举的标识。 |

## 输出信号及其语义

| 输出信号 | 形状 | 语义 |
|---|---:|---|
| `tag` | 标量 | 绑定提取内容、消息长度、策略 nonce 和选举标识的覆盖授权标签。 |

## 必须满足的关键安全与功能性质

1. **长度确定性**：消息长度必须由 `encodedPoint` 中规定的长度字段唯一确定。
2. **选择值有效**：每个 `selected[i]` 必须是 `0` 或 `1`。
3. **内容一致性**：提取结果必须逐位置对应输入字节和选择值。
4. **摘要绑定**：提取内容的摘要必须等于 `expectedBodyDigest`。
5. **授权域绑定**：最终标签必须绑定消息长度、策略 nonce 和 `electionId`。
6. **编码一致性**：满足约束的 witness 必须表示同一份编码数据及其唯一解释。

## 必要术语

- **SIV**：面向安全、隐私和可验证性的互联网投票系统。
- **Private Override**：通过受保护流程私密覆盖先前投票选择的机制。
- **序列化点**：把曲线点或相关结构编码为字节序列后的表示。
- **长度字段**：编码数据中声明有效消息长度的元数据。
- **Nonce**：用于区分不同操作并降低结果被复用风险的一次性或上下文值。
- **摘要**：将一组数据确定性汇总为固定大小值的结果。
